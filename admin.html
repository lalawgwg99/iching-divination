收款設定

買家下單時會看到你開的付款方式。LINE Pay Money 的「轉帳代碼」去 LINE → 錢包 → LINE Pay → iPASS MONEY → 轉帳代碼 找，不用加好友就能收。

API 金鑰

別的網站要串接兌換碼系統時，在這裡產生一組 key 給對方。對方只能做你勾選的事（開通／查詢／扣次數），不能發碼、不能看訂單。key 明碼只顯示一次，弄丟就撤銷重發。

待確認收款

客人付款後會在這裡出現。銀行轉帳就去查銀行帳對末五碼；LINE Pay 就去 LINE 錢包查帳，對顯示名稱和金額。對得上就按「確認收款並發碼」，系統自動產生密碼＋開通連結，你複製傳給客人就行。對不上就按「退回」。
